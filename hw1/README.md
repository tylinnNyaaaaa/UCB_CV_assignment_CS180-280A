# 程式設計作業一（proj1）
CS180：電腦視覺與計算攝影導論
俄羅斯帝國的影像：普羅庫丁-戈爾斯基照片集上色

概述
將三個色版影像疊合並對齊，合成為單張RGB彩色影像。我們假設簡單的XY平移模型即足以完成對齊。但全尺寸玻璃板影像（.tif檔）非常大，因此對齊程序必須相對快速有效率。

細節
玻璃板影像的濾鏡順序由上至下為BGR（不是RGB）。程式需將影像等分為三部分，並將第二（G）和第三（R）部分對齊到第一部分（B），同時輸出所使用的(x, y)位移向量。
對齊方法：

### 暴力搜尋法：在一定範圍內（如 [-15, 15] 像素）窮舉所有可能位移，以影像匹配指標評分，取最佳位移。常用指標包括：

    L2範數（歐幾里得距離）：sqrt(sum((image1 - image2)²))
    正規化互相關（NCC）：兩個正規化向量的內積


### 影像金字塔（多尺度加速）：暴力搜尋在高解析度影像上效率過低，需實作影像金字塔——以不同縮放比例（通常每層縮小2倍）由粗到細逐層搜尋，遞迴更新估計值。


加分項目（額外加分）
以下為可選的進階功能，完成後可獲得額外分數：

自動裁切：偵測並去除照片邊緣的雜色邊框
自動對比調整：將像素強度重新縮放，使最暗為0、最亮為1
自動白平衡：估計光源並校正色偏
更好的色彩映射：找出更接近真實色彩的色彩空間轉換
更好的特徵：改用梯度或邊緣特徵取代原始像素進行對齊
更好的變換：除XY平移外，加入縮放與旋轉的搜尋
